# Guia de Instalação e Execução

## Requisitos
- Ambiente de Execução Java (JRE) versão 17 ou superior.

## Como Executar
Para executar o arquivo dfieldX.jar empacotado:
java -jar target/dfieldX.jar

### Forçando um Idioma Específico
- Português: java -Duser.language=pt -Duser.country=BR -jar target/dfieldX.jar
- Espanhol: java -Duser.language=es -Duser.country=ES -jar target/dfieldX.jar
- Francês: java -Duser.language=fr -Duser.country=FR -jar target/dfieldX.jar
- Russo: java -Duser.language=ru -Duser.country=RU -jar target/dfieldX.jar
- Inglês: java -Duser.language=en -Duser.country=US -jar target/dfieldX.jar
