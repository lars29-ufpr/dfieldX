# Guía de Instalación y Ejecución

## Requisitos
- Entorno de Ejecución Java (JRE) versión 17 o superior.

## Cómo Ejecutar
Para ejecutar el archivo empaquetado dfieldX.jar:
java -jar target/dfieldX.jar

### Forzando un Idioma Específico
- Español: java -Duser.language=es -Duser.country=ES -jar target/dfieldX.jar
- Portugués: java -Duser.language=pt -Duser.country=BR -jar target/dfieldX.jar
- Francés: java -Duser.language=fr -Duser.country=FR -jar target/dfieldX.jar
- Ruso: java -Duser.language=ru -Duser.country=RU -jar target/dfieldX.jar
- Inglés: java -Duser.language=en -Duser.country=US -jar target/dfieldX.jar
