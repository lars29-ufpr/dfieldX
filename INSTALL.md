# Installation & Execution Guide

## Requirements
- Java Runtime Environment (JRE) 17 or higher.

## Running the Application
To run the pre-packaged dfieldX.jar file:
java -jar target/dfieldX.jar

### Forcing a Specific Language
- Portuguese: java -Duser.language=pt -Duser.country=BR -jar target/dfieldX.jar
- Spanish: java -Duser.language=es -Duser.country=ES -jar target/dfieldX.jar
- French: java -Duser.language=fr -Duser.country=FR -jar target/dfieldX.jar
- Russian: java -Duser.language=ru -Duser.country=RU -jar target/dfieldX.jar
- English: java -Duser.language=en -Duser.country=US -jar target/dfieldX.jar
