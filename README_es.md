# dfieldX (Versión 1.1)

Aplicación de escritorio en JavaFX desarrollada para la visualización gráfica de campos de direcciones, análisis de ecuaciones diferenciales ordinarias (EDO) y exploración de modelos matemáticos aplicados.

---

## Internacionalización (i18n & L10n)
dfieldX cuenta con soporte nativo completo para 5 idiomas:
- Español (es)
- Inglés (en)
- Portugués (pt_BR)
- Francés (fr)
- Ruso (ru)
