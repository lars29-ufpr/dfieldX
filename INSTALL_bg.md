# Ръководство за инсталиране

# dfieldX и pplaneX

Това ръководство обяснява как да инсталирате и стартирате dfieldX и pplaneX на Windows, macOS и Linux.

Тези приложения изискват Java 21 или по-нова версия.

Не се изисква предварителна инсталация на Java. Това ръководство предполага, че Java все още не е инсталирана на вашия компютър.

---

# 1. Изтегляне на приложението

Изтеглете най-новото издание от GitHub:

- dfieldX: https://tinyurl.com/difieldx-ufpr

- pplaneX: https://tinyurl.com/pplanex-ufpr


Запазете изтегления JAR файл на място, което лесно можете да намерите по-късно, като например работния плот (Desktop) или папката "Изтегляния" (Downloads).

---

# 2. Windows

## Инсталиране на Java

1. Отворете вашия уеб браузър.
2. Посетете: https://adoptium.net/
3. Изтеглете Eclipse Temurin Java 21 LTS за Windows x64.
4. Стартирайте изтегления инсталатор.
5. В "Custom Setup" (Персонализирана инсталация) се уверете, че "Add to PATH" и "Associate .jar files" са активирани.
6. Завършете инсталацията.

## Проверка на инсталацията

Отворете Command Prompt и изпълнете:

    java -version

Всяка версия 21 или по-нова се поддържа.

## Стартиране на приложението

    java -jar dfieldX.jar

или

    java -jar pplaneX.jar

---

# 3. macOS

## Инсталиране на Java
1. Посетете https://adoptium.net/
2. Изтеглете най-новата Java LTS (21 или по-нова) за macOS.  
   * *Съвет:* Изберете `.dmg` инсталатора (напр. `jdk-21_macos-x64_bin.dmg` за Intel Macs или `aarch64` еквивалента за Apple Silicon M1/M2/M3/M4).
3. Стартирайте инсталатора и следвайте инструкциите на екрана.

## Организиране на приложението
За по-добра организация препоръчваме да преместите изтеглените файлове `dfieldX.jar` и `pplaneX.jar` във вашата папка **Applications** (Приложения).

## Първо стартиране (Преодобляване на Gatekeeper)
macOS включва функция за сигурност, която блокира приложения от неидентифицирани разработчици. Ако просто щракнете двукратно върху `.jar` файла за първи път, macOS ще покаже предупреждение и ще предотврати отварянето му.

1. **Не щраквайте двукратно** върху файла първия път.
2. Вместо това, **щракнете с десния бутон** (или Control-щракване) върху `.jar` файла и изберете **Open** (Отвори) от контекстното меню.
3. Ще се появи диалогов прозорец с искане за потвърждение. Щракнете отново върху **Open**.
4. **Нормално използване:** Това е необходимо само веднъж. За всички последващи използвания можете просто да щракнете двукратно върху `.jar` файла, за да стартирате приложението нормално.

## Стартиране чрез терминал (Алтернатива)
Ако предпочитате командния ред, отворете Terminal и изпълнете:
    java -jar dfieldX.jar
или
    java -jar pplaneX.jar

# 4. Linux (Ubuntu, Debian, Linux Mint)

Инсталиране на Java:

    sudo apt update
    sudo apt install openjdk-21-jre

Проверка:

    java -version

Стартиране:

    java -jar dfieldX.jar

или

    java -jar pplaneX.jar

---

# 5. Linux (Fedora, Rocky Linux, AlmaLinux)

Проверка:

Стартиране:

    java -jar dfieldX.jar

или

    java -jar pplaneX.jar

Проверка:

Стартиране:

    java -jar dfieldX.jar

или

    java -jar pplaneX.jar

# Отстраняване на неизправности

## Нищо не се случва при двукратно щракване върху JAR файла

Стартирайте приложението от терминал:

    java -jar dfieldX.jar

или

    java -jar pplaneX.jar

## Грешка Unsupported Class Version Error

Инсталирайте Java 21 или по-нова версия.

## Приложението не стартира

Проверете:

    java -version

и докладвайте за всички съобщения за грешки на разработчика.
