# Guide d'Installation et d'Exécution

## Prérequis
- Environnement d'Exécution Java (JRE) version 17 ou supérieure.

## Comment Exécuter
Pour exécuter le fichier empaqueté dfieldX.jar :
java -jar target/dfieldX.jar

## Forcer une Langue Spécifique
- Français : java -Duser.language=fr -Duser.country=FR -jar target/dfieldX.jar
- Anglais : java -Duser.language=en -Duser.country=US -jar target/dfieldX.jar
- Portugais : java -Duser.language=pt -Duser.country=BR -jar target/dfieldX.jar
- Espagnol : java -Duser.language=es -Duser.country=ES -jar target/dfieldX.jar
- Russe : java -Duser.language=ru -Duser.country=RU -jar target/dfieldX.jar
