# Installation : dfieldX

🌍 [English](INSTALL.md) | 🇧🇷 [Português](INSTALL_pt_BR.md) | 🇪🇸 [Español](INSTALL_es.md) | 🇫🇷 [Français](INSTALL_fr.md)

### ☕ Prérequis
- **Java 11** (ou supérieur) doit être installé sur votre système.

### 🚀 Comment exécuter
1. Téléchargez la dernière version de `dfieldX.jar` depuis la section **Releases**.
2. Ouvrez votre terminal, naviguez jusqu'au dossier de téléchargement et exécutez :

    ```bash
    java -jar dfieldX.jar
    ```
