# dfieldX (Version 1.1)

Desktop application in JavaFX developed for graphical visualization of direction fields, analysis of ordinary differential equations (ODEs), and exploration of applied mathematical models.

---

## Internationalization (i18n & L10n)
dfieldX features full native support for 5 languages:
- English (en)
- Portuguese (Brazil) (pt_BR)
- Spanish (es)
- French (fr)
- Russian (ru)
