# dfieldX (Version 1.1)

Application de bureau en JavaFX développée pour la visualisation graphique de champs de directions, l'analyse d'équations différentielles ordinaires (EDO) et l'exploration de modèles mathématiques appliqués.

---

## Internationalisation (i18n & L10n)
dfieldX dispose d'un support nativo complet pour 5 langues :
- Français (fr)
- Anglais (en)
- Portugais (pt_BR)
- Espagnol (es)
- Russe (ru)
