# dfieldX — Чисельний та якісний аналіз 1D ЗДР

**dfieldX** — це сучасний інтерактивний десктопний застосунок, створений за допомогою Java 21 та JavaFX для чисельного моделювання, візуалізації полів напрямків та якісного аналізу скалярних звичайних диференціальних рівнянь (ЗДР) першого порядку:

$$x' = \frac{dx}{dt} = f(t, x)$$

Натхненний класичним освітнім програмним забезпеченням `dfield`, спочатку розробленим **Джоном К. Полкінгом** (Університет Райса) для MATLAB, **dfieldX** був переписаний з нуля, щоб забезпечити високу обчислювальну продуктивність, сучасний інтерфейс з GPU-прискоренням та універсальну кросплатформну портативність (Linux, Windows та macOS).

## 📥 Встановлення та швидкий старт

**dfieldX** поширюється як автономний виконуваний JAR-файл і вимагає **Java 21 (LTS) або новішої версії**.

Якщо у вас не встановлено Java або вам потрібні покрокові інструкції для вашої операційної системи (Windows, macOS або Linux), перегляньте наші посібники зі встановлення:

- 📖 **[Посібник зі встановлення (Українська)](INSTALL_uk.md)**

### Запуск програми

Після встановлення Java 21+ виконайте у терміналі:

```bash
java -jar dfieldX.jar
```

## 🚀 Основні можливості

- **Поля напрямків високої чіткості:** Плавний векторний рендеринг сегментів нахилу з опціями нормалізації довжини та розфарбовування за інтенсивністю нахилу.
- **Високоточне адаптивне чисельне інтегрування:**
  * Розв'язувачі зі стандартним та адаптивним кроком (Dormand-Prince / Runge-Kutta 4-го та 5-го порядку, стандартний RK4 та метод Ейлера).
  * Нативне обчислення дійсної функції кубічного кореня ($\text{cbrt}$) на всій множині $\mathbb{R}$, що усуває фазові артефакти розриву гілок.
- **Автоматизований якісний аналіз:**
  * Чисельне знаходження рівноваг ($f(t, x^*) = 0$).
  * Класифікація лінійної стійкості (атрактори, репелери та напівстійкі/сідлові точки).
  * Автоматична побудова ізоклін за допомогою контурного алгоритму *Marching Squares*.
  * Допоміжна діаграма фазової прямої ($x' \text{ vs } x$) для автономних рівнянь.
- **Вбудована галерея обраних моделей:** Колекція з 22 попередньо налаштованих моделей, що охоплюють:
  * Біоматематику та динаміку популяцій (Логістичне зростання, ефект Оллі, модель Гомпертца, вилов із постійним зусиллям та фіксованою квотою).
  * Класичну механіку та фізику (Вільне падіння з лінійним та квадратичним опором, RC-ланцюги, закон охолодження Ньютона).
  * Хімічну кінетику та базові еталонні ЗДР.
- **Повзунки параметрів у реальному часі:** Інтерактивні елементи керування для динамічного налаштування параметрів та безперервного дослідження біфуркацій.
- **Експорт векторної та растрової графіки високої роздільної здатності:**
  * Чиста масштабована векторна графіка (**SVG**) для публікацій та інтеграції з LaTeX.
  * Растровий експорт із високим DPI (**PNG**) із підтримкою прозорого фону (альфа-канал RGBA).
- **Універсальний кросплатформний Fat JAR:** Автономний виконуваний файл, що містить нативні графічні бібліотеки для **Linux (x86_64)**, **Windows (x86_64)** та **macOS (Apple Silicon M-Series та Intel x86_64)**.
