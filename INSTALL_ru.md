# Инструкция по установке и запуску

## Системные требования
- Среда выполнения Java (JRE) версии 17 или выше (рекомендуется Java 21).
- Поддерживаемые операционные системы:
  - Linux (Ubuntu, Fedora, Arch Linux, Mint и др.)
  - Windows 10 / 11
  - macOS (Intel & Apple Silicon)

## Запуск готового приложения (.jar)
Для запуска приложения напрямую без сборки из исходного кода убедитесь, что Java установлена, и выполните в терминале или командной строке:

java -jar target/dfieldX.jar

###Примечания для конкретных ОС:
- Linux: Убедитесь, что ваша графическая оболочка поддерживает отрисовку JavaFX (установлены библиотеки GTK3). Откройте терминал в каталоге приложения и выполните команду.
- Windows: Откройте Командную строку (cmd) или PowerShell в папке приложения и выполните команду. Убедитесь, что Java добавлена в системную переменную PATH.
- macOS: Откройте Терминал, перейдите в папку приложения с помощью команды cd и выполните команду. Убедитесь, что окружение Java настроено правильно.

## Принудительный выбор языка через командную строку
Вы можете переопределить язык интерфейса независимо от настроек операционной системы:

- Русский:
  java -Duser.language=ru -Duser.country=RU -jar target/dfieldX.jar
- Английский:
  java -Duser.language=en -Duser.country=US -jar target/dfieldX.jar
- Португальский:
  java -Duser.language=pt -Duser.country=BR -jar target/dfieldX.jar
- Испанский:
  java -Duser.language=es -Duser.country=ES -jar target/dfieldX.jar
- Французский:
  java -Duser.language=fr -Duser.country=FR -jar target/dfieldX.jar

## Разработка и Сборка из исходного кода
Если вы хотите скомпилировать и упаковать приложение из исходного кода с помощью Maven:
mvn clean package
