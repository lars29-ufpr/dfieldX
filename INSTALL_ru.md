# dfieldX - Инструкция по установке и запуску

## Требования
- Установленная среда выполнения Java (JRE) версии 17 или выше.

## Запуск приложения
Для запуска скомпилированного файла `dfieldX.jar` выполните в терминале:

java -jar target/dfieldX.jar

## Запуск на определенном языке
Чтобы принудительно запустить приложение на нужном языке (например, на русском):

java -Duser.language=ru -Duser.country=RU -jar target/dfieldX.jar
