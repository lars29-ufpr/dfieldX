# dfieldX — Численный и качественный анализ одномерных ОДУ

**dfieldX** — это современное интерактивное настольное приложение, созданное на базе Java 21 и JavaFX для численного моделирования, визуализации полей направлений и качественного анализа скалярных обыкновенных дифференциальных уравнений (ОДУ) первого порядка:

$$x' = \frac{dx}{dt} = f(t, x)$$

Вдохновленный классическим образовательным программным обеспечением dfield, первоначально разработанным **Джоном Ч. Полкингом (John C. Polking)** (Университет Райса) для MATLAB, **dfieldX** был написан с нуля для обеспечения высокой вычислительной производительности, современного графического интерфейса с ускорением на GPU и универсальной кроссплатформенной совместимости (Linux, Windows и macOS).

## 📥 Установка и быстрый старт

**dfieldX** распространяется в виде автономного исполняемого JAR-файла и требует **Java 21 (LTS) или новее**.

Если у вас не установлена Java или вам нужны пошаговые инструкции для вашей операционной системы (Windows, macOS или Linux), ознакомьтесь с нашим руководством по установке:

- 📖 **[Инструкция по установке (Русский)](INSTALL_ru.md)**

### Запуск приложения

После установки Java 21+ выполните в терминале:

    java -jar dfieldX.jar

## 🚀 Основные возможности

- **Поля направлений высокого разрешения:** Плавная векторная отрисовка сегментов наклона с опциями нормализации длины и раскраски по интенсивности наклона.
- **Высокоточное адаптивное численное интегрирование:**
  * Решатели со стандартным и адаптивным размером шага (Дорман-Принс / Рунге-Кутта 4-го и 5-го порядка, стандартный RK4 и метод Эйлера).
  * Нативное вычисление кубического корня (cbrt) в вещественной области на всем множестве $\mathbb{R}$, устраняющее артефакты фазы на разрезах.
- **Автоматизированный качественный анализ:**
  * Численное нахождение точек равновесия ($f(t, x^*) = 0$).
  * Линейная классификация устойчивости (аттракторы, репеллеры и полуустойчивые/седловые точки).
  * Автоматическая трассировка изоклин с использованием алгоритма *Marching Squares* (марширующие квадраты).
  * Вспомогательная фазовая диаграмма ($x' \text{ vs } x$) для автономных уравнений.
- **Встроенная галерея моделей:** Коллекция из 22 предварительно настроенных моделей, охватывающих:
  * Биоматематику и популяционную динамику (логистический рост, эффект Олли, модель Гомперца, сбор урожая с постоянным усилием и фиксированной квотой).
  * Классическую механику и физику (свободное падение с линейным и квадратичным сопротивлением, RC-цепи, закон охлаждения Ньютона).
  * Химическую кинетику и базовые тесты ОДУ.
- **Ползунки параметров в реальном времени:** Интерактивные элементы управления для динамической настройки параметров и непрерывного исследования бифуркаций.
- **Экспорт векторной и растровой графики высокого разрешения:**
  * Масштабируемая векторная графика (**SVG**) для публикаций и интеграции с LaTeX.
  * Растровый экспорт с высоким DPI (**PNG**) с поддержкой прозрачного фона (альфа-канал RGBA).
- **Универсальный кроссплатформенный Fat JAR:** Автономный исполняемый файл, включающий нативные графические бинарные файлы для **Linux (x86_64)**, **Windows (x86_64)** и **macOS (Apple Silicon M-Series и Intel x86_64)**.
