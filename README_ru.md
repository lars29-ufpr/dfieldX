# dfieldX (Версия 1.1)

Настольное приложение на JavaFX, разработанное для графической визуализации полей направлений, анализа обыкновенных дифференциальных уравнений (ОДУ) и исследования прикладных математических моделей.

---

## Интернационализация (i18n & L10n)
dfieldX имеет полную нативную поддержку 5 языков:
- Русский (ru)
- Английский (en)
- Португальский (pt_BR)
- Испанский (es)
- Французский (fr)
