# dfieldX — Численный и качественный анализ 1D ОДУ

**dfieldX** — это современное интерактивное десктопное приложение, созданное на Java 21 и JavaFX для численного моделирования, визуализации поля направлений и качественного анализа скалярных обыкновенных дифференциальных уравнений (ОДУ) первого порядка:

$$x' = \frac{dx}{dt} = f(t, x)$$

Вдохновленный классической образовательной программой `dfield`, первоначально разработанной **Джоном К. Полкингом** (Университет Райса) для MATLAB, **dfieldX** был переписан с нуля, чтобы обеспечить высокую вычислительную производительность, современный интерфейс с GPU-ускорением и универсальную кроссплатформенную совместимость (Linux, Windows и macOS).

---

## 📥 Установка и быстрый старт

**dfieldX** распространяется как автономный исполняемый JAR-файл и требует **Java 21 (LTS) или новее**.

Если у вас не установлена Java или вам нужно пошаговое руководство для вашей операционной системы (Windows, macOS или Linux), см. наши руководства по установке:

- 📖 **[Руководство по установке (Русский)](INSTALL_ru.md)**

### Запуск приложения

После установки Java 21+ выполните в терминале:

```bash
java -jar dfieldX.jar
```

## 🚀 Основные возможности

- **Поля направлений высокой четкости:** Плавный векторный рендеринг сегментов наклона с опциями нормализации длины и раскраски по интенсивности наклона.
- **Высокоточное адаптивное численное интегрирование:**
  * Решатели со стандартным и адаптивным шагом (Dormand-Prince / Runge-Kutta 4-го и 5-го порядка, стандартный RK4 и метод Эйлера).
  * Нативное вычисление действительного кубического корня ($\text{cbrt}$) на всем множестве $\mathbb{R}$, устраняющее артефакты фазы при разрывах ветвей.
- **Автоматизированный качественный анализ:**
  * Численное нахождение равновесий ($f(t, x^*) = 0$).
  * Классификация линейной устойчивости (аттракторы, репеллеры и полуустойчивые/седловые точки).
  * Автоматическое построение изоклин с помощью контурного алгоритма *Marching Squares*.
  * Вспомогательная диаграмма фазовой прямой ($x' \text{ vs } x$) для автономных уравнений.
- **Встроенная галерея выбранных моделей:** Коллекция из 22 предварительно настроенных моделей, охватывающих:
  * Биоматематику и динамику популяций (Логистический рост, эффект Олли, модель Гомпертца, вылов с постоянным усилием и фиксированной квотой).
  * Классическую механику и физику (Свободное падение с линейным и квадратичным сопротивлением, RC-цепи, закон охлаждения Ньютона).
  * Химическую кинетику и базовые эталонные ОДУ.
- **Ползунки параметров в реальном времени:** Интерактивные элементы управления для динамической настройки параметров и непрерывного исследования бифуркаций.
- **Экспорт векторной и растровой графики высокого разрешения:**
  * Чистая масштабируемая векторная графика (**SVG**) для публикаций и интеграции с LaTeX.
  * Растровый экспорт с высоким DPI (**PNG**) с поддержкой прозрачного фона (альфа-канал RGBA).
- **Универсальный кроссплатформенный Fat JAR:** Автономный исполняемый файл, содержащий нативные графические библиотеки для **Linux (x86_64)**, **Windows (x86_64)** и **macOS (Apple Silicon M-Series и Intel x86_64)**.
