Tutoriel dfieldX

1. Introduction

dfieldX est un outil interactif conçu pour l'étude qualitative des Équations Différentielles Ordinaires (EDO) du premier ordre. Il permet de visualiser rapidement des champs de directions et de tracer des courbes intégrales (solutions) à partir de conditions initiales.

2. Utilisation de Base

  • Définir l'équation : Dans la fenêtre principale, entrez votre équation sous la forme dx/dt = f(t, x). Vous pouvez modifier les noms des variables indépendante (ex: t) et dépendante (ex: x).
  • Fenêtre d'affichage : Définissez les limites du graphique en remplissant les champs des valeurs minimales et maximales pour les deux axes.
  • Tracer le champ : Cliquez sur le bouton Tracer pour générer le champ de directions.
  • Solutions initiales : Une fois le champ affiché, cliquez n'importe où sur le graphique pour tracer la solution passant par ce point (condition initiale).

3. Modèles Classiques

  • Croissance Exponentielle : dx/dt = r*x
    (Modélise une croissance de population sans restriction).
  • Croissance Logistique : dx/dt = r*x*(1 - x/K)
    (Modélise une population avec une capacité de charge K).
